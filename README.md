# Bermula

<div data-full-width="false"><figure><img src=".gitbook/assets/chloros_logo_transparent.png" alt=""><figcaption></figcaption></figure></div>

Chloros ialah aplikasi perisian daripada [MAPIR](https://www.mapir.camera) untuk memproses imej dan data penderia lain.

***{% hint style="success" %}**Apa yang Baharu dalam Chloros 1.1.0**: Sokongan Linux asli (amd64 dan arm64), pengkomputeran tepi NVIDIA Jetson, Penyesuaian Pengiraan Dinamik, saluran paip pemprosesan 4-benang, arahan dan pilihan CLI baharu. Lihat [Muat Turun](download.md) untuk log perubahan penuh.
{% endhint %}

Chloros tersedia dalam 3 mod aplikasi:

## Chloros: Aplikasi GUI Desktop

Tetingkap berasingan yang berdiri sendiri dengan semua ciri. _Windows sahaja._

## [Chloros CLI: Antara muka baris arahan](CLI.md)

Pemprosesan kelompok baris arahan. Sesuai untuk automasi, skrip dan operasi tanpa kepala. Tersedia pada **Windows, Linux amd64 dan Linux arm64 (NVIDIA Jetson)**. _CLI memerlukan lesen Chloros+ untuk mengakses._

## [Chloros API: Python SDK](api-python-sdk.md)

Antara muka Python terprogram untuk automasi dan aliran kerja tersuai. Sesuai untuk saluran paip penyelidikan, penyepaduan dengan aplikasi Python sedia ada, dan membina alatan tersuai. Tersedia pada **semua platform** melalui `pip install chloros-sdk`. _API memerlukan lesen Chloros+ untuk mengakses._***

## Platform yang Disokong

| Platform | GUI | CLI | Python SDK |
| --- | --- | --- | --- |
| **Windows 10/11** | Ya | Ya | Ya |
| **Linux amd64 (x86_64)** | Tidak | Ya | Ya |
| **Linux arm64 (NVIDIA Jetson)** | Tidak | Ya | Ya |

Untuk arahan pemasangan Linux, lihat bahagian [Linux & Edge Computing](linux/linux-overview.md).

***

## Chloros+

Walaupun Chloros percuma untuk digunakan untuk kebanyakan tugasan, anda mungkin mendapati anda mahukan lebih banyak lagi. Di situlah lesen berbayar untuk Chloros+ boleh memberi manfaat kepada anda. Dengan lesen Chloros+ anda boleh membuka kunci ciri baharu seperti:

* **Pemprosesan Berbilang Thread**: sangat mempercepatkan pemprosesan imej untuk projek yang lebih besar dengan memproses imej secara serentak melalui saluran paip.
* **Pecutan GPU (CUDA)**: manfaatkan pilihan memori GPU yang lebih tinggi hari ini untuk mempercepatkan lagi saluran pemprosesan imej. Kami mengesyorkan 4GB atau lebih daripada VRAM untuk hasil terbaik.
* **Chloros+**[**CLI**](CLI.md)**Akses**: jalankan Chloros+ daripada baris arahan untuk mengautomasikan dan menyepadukan ke dalam perisian anda sendiri.
* **Chloros+**[**API**](api-python-sdk.md)**Akses:** jalankan Chloros+ daripada Python untuk kawalan program, membolehkan penyepaduan lancar, saluran kerja penyelidikan data anda.
* **Penggunaan Berbilang Peranti**: setiap lesen Chloros+ membenarkan 2+ peranti didaftarkan. Gunakan akaun Awan MAPIR anda untuk mengurus peranti berdaftar. Tambahkan sokongan untuk lebih banyak peranti dengan menaik taraf lesen Chloros+ anda.
* **Kaedah Debayer Sedar Tekstur Lanjutan:** debayer sedar tepi berkualiti tinggi digabungkan dengan model denoising AI/ML yang menghilangkan hampir semua bunyi debayering.&#x20;
* **Formula Indeks Berbilang Spektrum Tersuai:** masukkan indeks berbilang spektrum tersuai dalam kalkulator raster Chloros, kedua-duanya untuk pemprosesan dan kotak pasir melihat imej.
* **Linux & Edge Computing:** jalankan Chloros pada Linux x86\_64 dan platform ARM64 termasuk NVIDIA Jetson untuk pemprosesan medan dan tepi. Lihat [Linux Gambaran Keseluruhan](linux/linux-overview.md).
