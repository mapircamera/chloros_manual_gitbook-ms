# GUI : Projek

Chloros membolehkan anda membuat projek yang boleh dibuka semula pada masa hadapan.

## Projek Baharu

<figure><img src=".gitbook/assets/project_new.JPG" alt=""><figcaption></figcaption></figure>

Pilih "Projek Baharu" daripada menu utama dan masukkan nama unik untuk projek anda.

## Projek Terbuka

<figure><img src=".gitbook/assets/project_open.JPG" alt=""><figcaption></figcaption></figure>

Pilih "Buka Projek" untuk melihat senarai projek sedia ada dalam Folder Projek. Jika tiada projek wujud menu sampingan sekunder tidak akan dibuka. Anda boleh melihat beberapa projek ciptaan GUI (t1, t2, t3) disenaraikan dalam foto di atas. Projek DATE\_TIME telah dibuat oleh CLI menggunakan skema penamaan projek lalai. Mengklik mana-mana nama projek akan membukanya.

Mengklik butang "Buka Folder Projek" membuka penjelajah fail komputer anda di laluan projek. Anda boleh melaraskan laluan projek dalam [Tetapan Projek](project-settings/project-settings.md).

## Tambah Fail

Selepas projek dibuka, pilih "Tambah Fail" daripada menu utama untuk menambah fail imej individu pada projek semasa. Ini mencerminkan fungsi tambah penyemak imbas fail tetapi boleh diakses terus dari menu utama untuk kemudahan.

## Tambah Folder

Selepas projek dibuka, pilih "Tambah Folder" daripada menu utama untuk menambah keseluruhan folder imej pada projek semasa. Fail pendua diabaikan.

## Mula / Hentikan Pemprosesan

Selepas fail ditambahkan pada projek, "Mulakan Pemprosesan" tersedia dalam menu utama. Ini adalah tindakan yang sama seperti mengklik butang Main/Mula di pengepala atas. Semasa pemprosesan, item menu bertukar kepada "Hentikan Pemprosesan" untuk membolehkan anda menghentikan saluran paip.

{% hint style="info" %}
Item menu Tambah Fail, Tambah Folder dan Mula/Berhenti Memproses hanya kelihatan atau didayakan apabila projek dibuka dan fail telah ditambahkan. Mereka menyediakan akses pantas kepada tindakan yang juga tersedia melalui bar sisi dan butang pengepala Pelayar Fail.
{% endhint %}
